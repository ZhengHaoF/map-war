## 二、达标项（亮点，保持）

1. **地图是真·直接操作**：`onPointerMove` 逐帧跟随指针；`onWheel` 缩放以鼠标位置为锚点（`LeafletMap.vue:1076-1079`），符合 §2 的「内容跟随手指、尊重抓取点」。
2. **镜头补间可中断**：`animateCameraTo` 用 `requestAnimationFrame`，带 `cameraInterrupt` 标志，ESC 调 `cancel()` 能中途收住（`LeafletMap.vue:1047`），这是 §3 的核心要求。
3. **点击/拖拽区分**：5px 移动阈值（`LeafletMap.vue:1111`）避免误触，符合 §10 的 hysteresis。
4. **Toast 重排过渡顺**：`TransitionGroup` 配 `.toast-move`，新增/移除时其余卡片平滑位移（`ToastStack.vue:52`），是 §7 的好实践。
5. **AI 操作台折叠**：`dock-collapse` 进/出均 `translateY(-8px)` + 淡入淡出，同路径、同缓动（`PlayerAiPanel.vue:206`），方向一致。

## 三、问题项（按优先级）

> **全部已修复（2026-07-18 代码复核确认）**。以下保留原始问题描述作为记录，实际状态以「修复落地」节为准。

### 🔴 P0 — 规范硬伤 / 可访问性

**P0-1　完全缺失 `prefers-reduced-motion`（§14）** ✅ 已修复
全站大量动效（Toast、Modal 出现、镜头、折叠），但没有任何 `@media (prefers-reduced-motion: reduce)` 处理。前庭敏感用户会直接被晃到。
修复：在 `App.vue`（全局）补一段，把所有位移/缩放降级为短淡入淡出：
```css
@media (prefers-reduced-motion: reduce) {
  .toast-enter-active, .toast-leave-active,
  .dock-collapse-enter-active, .dock-collapse-leave-active {
    transition: opacity 0.2s ease !important;
  }
  .toast-enter-from, .toast-leave-to,
  .dock-collapse-enter-from, .dock-collapse-leave-to {
    transform: none !important;
  }
}
```
（Modal 当前连动画都没有，见 P0-2，补齐后同样要纳入。）

**P0-2　Modal 无入场/退场动画（§7 / §12）** ✅ 已修复
`GameModal.vue` 的 `<div v-if="visible">` **没有 `<Transition>` 包裹**，弹窗和遮罩都是瞬时出现、瞬时消失。规范 §12 明确要求「Materialize, don't just fade」——用模糊半径 + 缩放一起进场，让表面像真实材质抵达。
修复：在 `Teleport` 内给 `.modal-overlay` 包 `<Transition name="modal">`，并让 `.modal` 从 `scale(0.96)` + `blur` 渐入，退场原路返回；遮罩同步淡入。注意遮罩与弹窗要各自过渡，且**进出同一路径**。

**P0-3　按钮缺按下反馈（§1）** ✅ 已修复
`GameButton.vue`、图层器按钮、势力卡片、开战/读取按钮，都只有 `:hover`，没有 `:active` 按压态。规范 §1 首条就是「在 pointer-down 就反馈，而非等 click/抬起」。
修复：补
```css
.game-btn:active { transform: scale(0.96); transition: transform 80ms ease-out; }
```
卡片/大按钮同理加 `:active { transform: translateY(0) scale(0.98); }`。

### 🟠 P1 — 运动质量缺陷

**P1-1　Toast 进/出路径不一致（§7）** ✅ 已修复
`ToastStack.vue`：进 `translateY(-14px)`（从上方），出 `translateX(28px)`（向右）。规范要求「从哪进就从哪出」。改成统一方向——例如进出都从右上方滑入/滑出，或进出都用 `translateY`。

**P1-2　缩放/平移硬边界（§9）** ✅ 已修复
`LeafletMap.vue:1074` 把 `mapScale` 死夹在 `[0.5, 8]`，拖到边缘直接「冻住」。规范要橡皮筋：越界后渐进阻力（`rubberband()` 函数）。至少给越界一点点回弹/缓阻，读起来才「还活着」。

**P1-3　`transition: all` 过渡了渐变背景（§11）** ✅ 已修复
`.game-btn`、`.layer-switcher button`、`.faction-card` 都 `transition: all 0.15s/0.2s`，同时过渡 `background`（渐变）与 `box-shadow`。渐变背景无法被合成器加速，会触发重绘，快速 hover 时可能掉帧。
修复：把 `transition` 收窄为 `transform 0.15s ease, box-shadow 0.15s ease, color 0.15s ease`，背景用 hover 直接换（或叠一层 `::before` 做 opacity 过渡）。

### 🟡 P2 — 可选增强（非硬性不达标）

- **P2-1 镜头用弹簧 + 速度交接（§4/§5）**：`animateCameraTo` 现在是 `easeOutCubic` 定长补间，没有把拖拽松手的速度接上。可换弹簧（如 Motion 的 `spring`，`damping:1.0` 默认、镜头类 `response:0.4`）。非手势触发的「聚焦」用临界阻尼弹簧即可，已经够顺；但若想更「活」，把 release velocity 传进去。
- **P2-2 拖拽惯性（§5/§6）**：地图松手即停，无动量投影。策略游戏可不加，但若希望「甩一下再滑一段」，用 `project()` 算法。
- **P2-3 上下文菜单缩放入场（§7/§12）**：`GameContextMenu.vue` 在点击点瞬时出现，没从触发点「生长」出来。加一个 `transform: scale(0.9)` + `transform-origin` 指向触发坐标的淡入即可。
- **P2-4 字距分级（§15）**：当前大标题用正字距（书法风取舍，对 CJK 合理），但可顺手把超大字（如「一九三一」）的 `letter-spacing` 略收，更接近「大字收紧」原则。属锦上添花。
