## 1. 数据模型

### 1.1 关系状态

```ts
// stores/game.ts 或独立 utils/diplomacy.ts
export type RelationStatus = 'war' | 'peace' | 'alliance'

export interface Relation {
  status: RelationStatus
  /** 停战冷却期截止日（ISO）；仅从 war→peace 时设置；在此日期前禁止再次宣战 */
  truceUntil?: string
}
```

### 1.2 关系键（对称归一化）

```ts
/** 对称键：两 Owner 按字母序拼接，保证 A-B === B-A */
export function relationKey(a: Owner, b: Owner): string {
  return [a, b].sort().join('-')
}
```

### 1.3 store 新增状态

```ts
// stores/game.ts
const relations = ref<Record<string, Relation>>({})
// 键 = relationKey(a, b)，值 = { status, truceUntil? }
// 未出现的键默认视为 peace（无需初始化 45 对）
```

### 1.4 新增 GameEvent

```ts
export type GameEvent =
  | ... // 现有 20+ 种
  | {
      type: 'relationChange'
      a: Owner            // 发起方（actor，叙事用）
      b: Owner            // 对象方
      status: RelationStatus
      truceUntil?: string // 仅 status='peace' 时有效
      note?: string       // 叙事备注（"九一八事变，日军悍然宣战"）
    }
```

## 2. Reducer（applyEvent 扩展）

在 `stores/game.ts` 的 `applyEvent` 中新增分支：

```ts
if (e.type === 'relationChange') {
  const key = relationKey(e.a, e.b)
  relations.value[key] = {
    status: e.status,
    truceUntil: e.status === 'peace' ? e.truceUntil : undefined,
  }
  return { ok: true }
}
```

### 2.1 preCheck 校验

```ts
case 'relationChange': {
  if (!e.a || !e.b) return { ok: false, reason: 'relationChange 需要 a 和 b 两个势力' }
  if (e.a === e.b) return { ok: false, reason: '不能对自身设置外交关系' }
  if (e.a === Owner.NEUTRAL || e.b === Owner.NEUTRAL) return { ok: false, reason: '中立无外交' }
  return { ok: true }
}
```

### 2.2 宣战冷却期校验（可选，放 preCheck 或战略校验层）

```ts
// 若从非 war → war，检查对方是否处于停战冷却期
if (e.status === 'war') {
  const key = relationKey(e.a, e.b)
  const cur = relations.value[key]
  if (cur?.truceUntil && e.date < cur.truceUntil) {
    return { ok: false, reason: `停战期未满（至 ${cur.truceUntil}），不可撕毁停战` }
  }
}
```

> 注意：preCheck 拿不到 currentDate，这个校验可放在 `executeOrder` / 战略校验层，或在事件上附带 `gameDate` 字段。

### 4.1 freeAction.effects 新增第八种

`aiOrderContract.ts` 的 `PLAYER_AI_UNIFIED_PROMPT` 中 effects 说明追加：

```
- relationChange：a + b + status("war"/"peace"/"alliance") + truceUntil?(停战截止日，仅 peace 时)
  · 宣战：{"type":"relationChange","a":"川军","b":"晋系","status":"war","note":"川军通电讨伐阎锡山"}
  · 停战：{"type":"relationChange","a":"川军","b":"晋系","status":"peace","truceUntil":"1932-06-01","note":"双方议和，停战三月"}
  · 结盟：{"type":"relationChange","a":"川军","b":"桂系","status":"alliance","note":"川桂联盟，共抗中央"}
  · 注意：宣战/结盟是重大外交动作，叙事务必交代动机；停战须给 truceUntil（1-6个月）
```

### 4.2 buildFactionContext 注入关系

`aiContext.ts` 的 `buildFactionContext` 末尾追加：

```ts
// 外交关系
const relLines: string[] = []
for (const f of snap.activeFactions) {
  if (f === faction) continue
  const key = relationKey(faction, f)
  const rel = snap.relations[key]
  const status = rel?.status ?? 'peace'
  if (status === 'peace' && !rel?.truceUntil) continue // 默认和平不占篇幅
  const label = OWNER_LABELS[f] ?? f
  if (status === 'war') relLines.push(`  ⚔ 与${label}：战争中`)
  else if (status === 'alliance') relLines.push(`  🤝 与${label}：同盟`)
  else if (rel?.truceUntil) relLines.push(`  🕊 与${label}：停战中（至 ${rel.truceUntil}）`)
}
if (relLines.length) {
  lines.push('')
  lines.push('外交关系：')
  relLines.forEach(l => lines.push(l))
}
```

### 4.3 Faction AI prompt 追加外交行为指引

在政权 AI 的 system prompt（`aiInvoke.ts` 或 `aiPromptBuilder.ts`）中追加：

```
═══ 外交行为 ═══
· 你可以通过 freeAction.effects 中的 relationChange 发起外交动作（宣战/停战/结盟）
· 处于"同盟"的势力不可攻击（battle/capture 的 to 不能是盟友的城市）
· 处于"停战"的势力不可攻击（除非停战期已过）
· 宣战需要合理动机（领土争端/背盟/利益冲突），不可无故宣战
· 结盟需要共同敌人或利益交换，不可凭空结盟
```

## 5. classifyFactions 升级

`aiClassify.ts` 的 `classifyFactions` 扩展：

```ts
export function classifyFactions(opts: {
  playerFaction: Owner | null
  activeFactions: Owner[]
  ownership: Record<string, Owner>
  eventLog: GameEvent[]
  relations?: Record<string, Relation>  // ← 新增
}): FactionClassification {
  // ... 现有逻辑（近期互动）...

  // 新增：处于战争或同盟的势力，无论近期有没有互动，都算 related
  if (opts.relations && playerFaction) {
    for (const f of activeFactions) {
      if (f === playerFaction) continue
      const key = relationKey(playerFaction, f)
      const rel = opts.relations[key]
      if (rel && (rel.status === 'war' || rel.status === 'alliance')) {
        related.add(f)
      }
    }
  }

  // ... 后续不变
}
```

调用处（`useAgentKernel.ts`）传入 `snap.relations`。

## 6. 开局播种（initWorld）

1931 年 4 月开局时的历史关系种子（不走事件，直接写 `relations`，同城市播种）：

```ts
function seedRelations(): Record<string, Relation> {
  const r: Record<string, Relation> = {}
  const set = (a: Owner, b: Owner, status: RelationStatus, truceUntil?: string) => {
    r[relationKey(a, b)] = { status, truceUntil }
  }
  // 中原大战刚结束：蒋 vs 阎/冯 停战
  set(Owner.KMT, Owner.SHX, 'peace', '1931-10-01')  // 蒋阎停战（冷却期）
  set(Owner.KMT, Owner.GXC, 'peace', '1931-10-01')  // 蒋桂停战
  // 国共内战
  set(Owner.KMT, Owner.CCP, 'war')
  // 其余默认 peace（不显式存）
  return r
}
```

## 7. UI 呈现

### 7.1 电报面板（TelegramPanel）频道头部加关系徽标

```vue
<span class="tg-rel-badge" :class="`tg-rel--${relationStatus(activeChannel)}`">
  {{ relationLabel(activeChannel) }}
</span>
```

```ts
function relationStatus(ch: string): string {
  if (ch === 'world') return ''
  const my = store.currentFaction
  if (!my) return 'peace'
  const key = relationKey(my, ch as Owner)
  return store.relations[key]?.status ?? 'peace'
}
function relationLabel(ch: string): string {
  const s = relationStatus(ch)
  if (s === 'war') return '交战'
  if (s === 'alliance') return '同盟'
  const rel = store.relations[relationKey(store.currentFaction!, ch as Owner)]
  if (rel?.truceUntil) return '停战'
  return ''  // 默认和平不显示
}
```

样式：交战=朱砂底、同盟=苍绿底、停战=土黄底，圆角小标签。

## 8. 战略校验扩展（aiOrderContract.ts）

`validateOwnedOrder` 新增外交约束：

```ts
// 6. battle / capture 的 to 不能是盟友或停战方的城市
if ((order.order === 'battle' || order.order === 'capture') && order.to) {
  const toId = resolveLocationId(order.to)
  if (toId) {
    const toOwner = cityOwnerFn(toId)
    if (toOwner && toOwner !== ownerFaction) {
      const key = relationKey(ownerFaction, toOwner)
      const rel = relationsFn?.(key)  // 需要传入 relations 查询函数
      if (rel?.status === 'alliance') {
        return { ok: false, reason: `不能攻击盟友「${OWNER_LABELS[toOwner]}」的领土` }
      }
      if (rel?.status === 'peace' && rel.truceUntil && currentDate < rel.truceUntil) {
        return { ok: false, reason: `与「${OWNER_LABELS[toOwner]}」停战期未满（至 ${rel.truceUntil}），不可背信进攻` }
      }
    }
  }
}
```

> 需要给 `validateOwnedOrder` 多传一个 `relationsFn` 和 `currentDate` 参数。
