# 烽火舆图 · Warlords 1931 游戏性评估

## 核心玩法循环

```
P1 玩家阶段（自然语言发令）
    ↓ 点「结束回合」
P2 世界AI调度（引擎分流：major→专属AI / minor→世界AI批量）
    ↓ 分流已发
P3 政权AI决策执行（并行LLM → 契约校验 → submit → 演出落地）
    ↓ 全部政权AI完成
P4 世界AI结算（读eventLog叙事 + 推进日期 + 自动存档）
    ↓ 新回合开始
```

这是一个**相当成熟的四阶段回合循环**，设计上借鉴了《文明》系列的"玩家行动→AI行动→结算"模式，但用自然语言指挥替代了传统UI操作。

---

## ✅ 游戏性亮点

### 1. 自然语言指挥系统（⭐⭐⭐⭐⭐）

玩家不需要学习复杂的UI操作，直接用中文说：

> "从成都出兵进攻汉中，留2k兵守家"

AI自动解析为结构化指令：

```json
{"order":"battle","from":"成都","to":"汉中","deployAmount":2}
```

**19条指令**覆盖军事、内政、系统管理：

| 类别 | 指令 | 说明 |
|------|------|------|
| 军事 | `arrowFly` | 行军动画（纯视觉） |
| 军事 | `battle` | 开启持续战斗 |
| 军事 | `capture` | 占领城市 |
| 军事 | `deploy` | 精确出兵 |
| 军事 | `reinforce` | 前线增援 |
| 内政 | `recruit` | 征兵 |
| 内政 | `develop` | 建设工业/粮食 |
| 内政 | `fortify` | 筑防 |
| 内政 | `rally` | 整军士气 |
| 系统 | `setFactionAlive` | 势力存亡 |
| 系统 | `setCurrentDate` | 时间跳跃 |

另有**自由行动路径**：办学、通电、暗杀、决堤、外交斡旋等开放行动，AI用叙事回应并可选地落地后果。

### 2. 十方势力博弈（⭐⭐⭐⭐）

| 势力 | 初始兵力 | 特点 |
|------|---------|------|
| 国民政府 | 170万 | 名义正统，内部分裂 |
| 中共苏区 | 4万 | 士气高昂，星星之火 |
| 日本关东军 | 2万精锐 | 装备精良，九一八触发 |
| 东北军 | 30万 | 兵工厂完备，抵抗or撤退 |
| 晋系 | 15万 | 两个鸡蛋上跳舞 |
| 桂系 | 10万 | 李白组合，善打硬仗 |
| 川军 | 30万 | 派系林立，二刘争川 |
| 马家军 | 5万骑兵 | 高原戈壁不可战胜 |
| 新疆 | 2万 | 地广人稀，苏联虎视 |
| 西藏 | 1万 | 天险据守，英印渗透 |

每个势力有独特的领袖、首都、兵力描述和战略困境，不是换皮AI。

### 3. 三层AI架构（⭐⭐⭐⭐⭐）

- **玩家军师AI**：解析自然语言→生成指令→结构校验→战略校验→执行
- **政权AI**：major势力（KMT/CCP/JPN/NEA/SHX/GXC）专属AI实例，minor势力（MA/XJ/TIB）世界AI批量代打
- **世界AI**：结算叙事、战斗裁决、日期推进

**校验体系完善**：
- 结构校验：城市码存在/枚举合法/日期格式（零LLM成本）
- 战略校验：capture只能为本方、不能打自己人、from须己方城
- 世界AI可行性裁定：feasible/impossible两档（极窄的impossible定义）

### 4. 电报系统（⭐⭐⭐⭐）

- **双频道**：`direct`（势力↔玩家私信）+ `world`（天下公屏）
- **AI自主发电报**：P3阶段专属AI可选输出`telegram`字段，零额外LLM调用（搭车已有生成）
- **进决策上下文**：势力AI决策时注入近6条direct电报，世界AI结算时注入近8条world发言
- **微信式UI**：左右分栏、势力色头像、未读红点、日期分段、线路呼吸灯

### 5. 顾问AI（⭐⭐⭐⭐）

- 场外战略顾问，只分析给建议**不执行**
- 输出格式：`{reply: "分析", suggestions: ["建议1", "建议2"]}`
- **建议→指挥闭环**：点击建议→自动填充到军师面板输入框（CustomEvent通信）

### 6. 事件溯源架构（⭐⭐⭐⭐⭐）

- 存档 = 序列化事件日志
- 读档 = 重放事件（不重跑AI）
- `applyEvent`是纯函数reducer，天然replay安全
- 战斗动画句柄不进store，读档时从`battles`元数据重建

### 7. 视觉演出（⭐⭐⭐⭐⭐）

- **PixiJS渲染**：弧线行军（多箭头/光球）、雷达扫描、战斗光束、占领冲击波
- **云雾蒙太奇**：全屏水墨云雾「盖住→停顿→散开」，用于时间跳跃
- **羊皮纸水墨风UI**：`--paper`/`--ink`/`--cinnabar`主题变量，楷/行楷字体
- **Toast系统**：羊皮纸轻提示，顶部居中滑入淡出，按事件类型着色

## ⚠️ 游戏性短板

### 1. 经济系统薄弱（❌ 字段存在但无循环）

`CityState`有`industry`/`food`字段，但：
- 没有税收机制（钱从哪来？）
- 没有资源消耗（养兵要不要钱？）
- 没有经济决策（投资工业还是农业？）
- `develop`指令可以+industry，但加了之后有什么产出？没有

**后果**：内政指令变成"数字游戏"，没有经济压力驱动玩家扩张。

### 2. 胜利条件缺失（❌ 无目标）

- 没有统一全国胜利
- 没有存活到最后胜利
- 没有历史线分支（如"抗战胜利""偏安一隅"）
- 没有分数/成就系统

**后果**：游戏可以无限进行，但没有目标感，玩家容易失去动力。

### 3. 外交系统未实现（⬜ 文档标记未实现）

文档中设计的"三段式外交对话"：

```
玩家自然语言 → 世界AI(校验+路由) → 目标阵营AI回应 → 世界AI收口
```

目前只有电报，没有：
- 结盟/互不侵犯条约
- 宣战/停战
- 借道/联合进攻
- 人质/联姻

### 4. 战斗结算简化（🟡 深度不足）

- 战斗 = 持续动画 + 每回合数值损耗
- 没有地形修正（山地防守+50%？）
- 士气影响弱（morale字段存在但结算公式中权重低）
- 没有将领技能/兵种克制
- 战斗裁决优先走LLM（贵），fallback用简单公式（各损6%）

### 5. 城市差异化不足（🟡）

380城有`cityLevel`(1-5)/`industry`/`food`/`fort`区分，但：
- 首都/大城市没有特殊能力
- 没有"核心城市丢失士气大降"的机制（文档提到但未硬实施）
- 城市名用1931历史名是亮点，但玩法上没体现

### 6. AI成本问题（⬜ 规则AI兜底未实现）

- 所有决策都走LLM（DeepSeek API）
- 没有基于规则的AI兜底（如`attackScore`启发式）
- 长期运行成本高，不适合挂机推演

## 总体评价

> **骨架极好，血肉待丰。**

**技术架构**（事件溯源、三层AI、自然语言指挥）是五星级的设计，在独立游戏中属于顶尖水平。

**视觉气质**（羊皮纸水墨风、PixiJS动画）有独特美学，与市面上主流策略游戏形成差异化。

**历史题材**（1931军阀割据）有教育意义和叙事潜力，"九一八"触发点设计巧妙。

**但"好玩"的核心循环尚未接通**：
- 没有经济压力→不需要扩张→没有紧迫感
- 没有胜利条件→没有目标→容易腻
- 没有外交→势力间只有战争→玩法单一

### 建议优先级

1. **胜利条件**（统一全国/存活到最后/历史线分支）— 让游戏有终点
2. **经济产出循环**（税收→征兵/建设，养兵消耗）— 制造扩张压力
3. **外交系统**（结盟/宣战/互不侵犯）— 增加博弈维度
4. **地形/士气对战斗的实质影响** — 让数据有意义
5. **规则AI兜底**（minor势力用启发式）— 降低LLM成本

如果把这五条补上，这会是一款非常有竞争力的独立策略游戏。
