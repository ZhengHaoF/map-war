# 西南短战役与回合节奏首版

上一轮短局暴露了目标依赖玩家自定、常规内政串行演出与大事记流水过多的问题。本轮用一个可选的川军目标链验证“夺取、整合、守住”的闭环，复用已有规则，不扩科技树或运输网络。

## 问题与目标

- **可理解的下一步**：开始战役后显示当前目标、三阶段条件和守住进度；不要求玩家再次询问模型才能看见完成条件。
- **完整回合计数**：昭通归属川军、宜宾仍属川军、昭通已整合且补给连通时，完成一个完整回合才增加守住计数；整合刚结束的那个时间跳转不提前算一回合。
- **规则不因演出改变**：相同的 AI 内政批次在完整/快速模式下产生完全相同的世界事件、费用、兵力与行动点，快速模式不调用常规内政动画。
- **摘要可扫读**：本方银粮合并显示；本方前线、外交和失败反馈保留，其他势力例行变化默认折叠，完整事件仍可查看。

## 不做的内容

本轮不缩减全国地图，不新增历史剧本真实性承诺、不调税粮或战斗系数、不发额外资源奖励，不改变全国胜负。只支持川军示范战役，不声称其他势力已有对应战役；快速模式不缩短模型服务响应、不跳过战斗或调兵演出。

## 玩家故事与要求

- **新玩家**：作为川军玩家，我能从战役入口开始“夺昭通、整合补给、连续守住三回合”，知道眼下该做什么。
- **已有存档玩家**：我能在旧存档开始目标链，但不能把开始前的回合充作守住进度；保存、读取应恢复已有进度。
- **战线受挫的玩家**：失去昭通或宜宾、断供或整合未完成时，未完成战役的连续守住计数立即清零；重新恢复后重新累计。
- **关注节奏的玩家**：我能开关 AI 内政快速演出；开关只影响可信调用方的常规内政表现，不影响普通玩家指令或任何规则检查。
- **复盘玩家**：我能展开其他势力合并信息和完整事件；摘要不替代、删除或修改事件日志。

## 验收边界

战役开始由 UI 产生 `scenarioStarted` 事件，不能通过 LLM GameOrder 直接完成。重复开始不得重置已有进度，完成后记录保留且全国沙盘可继续；进度按事件重放重建，旧存档没有开始事件则没有战役。

快速模式默认开启，偏好随存档保存，旧存档缺省开启。只有可信 `authority=faction` 的征兵、建设、筑防、整军可省略动画与成功提示；失败仍反馈，所有费用、行动点和合法性检查保留，模型 JSON 不能自行选择执行权限。

摘要属于世界推演结果切片，本方此前已执行的玩家指令仍在指挥与事件日志中。归属使用推演前快照辅助识别失地，不把失去的城市误当成无关变化；完整流水按需展开，避免丢失复盘细节。

## 验证指标与非阻塞问题

验收用固定批次动画调用次数、事件序列和世界快照一致性、完整回合进度及保存重放断言衡量，不预设未经实测的延迟下降比例或留存提升。还需后续真实玩家测试目标可理解性、十至十五回合节奏和敌方反击；首版没有自动证明它比开放沙盘更耐玩。

## 自动化验证

- **规则与存档**：8 项目标链测试覆盖完整回合计数、整合结束不抢算、失守或断供重置、开始前回合不计入、完成记录保留、重复开始和非川军拒绝、手动及自动存档重放、旧存档缺省偏好。
- **表现与摘要**：8 项测试覆盖录制的 25 条内政指令普通/快速模式的世界快照、事件序列、费用和回执完全一致，动画调用从 25 次变为 0 次；征兵、建设、筑防、整军四路径另作对照。玩家与模型 JSON 不得自行启用快速模式，非法归属、数值、资金不足和第七条行动仍拒绝，战斗动画保留。
- **归属与信息**：摘要以事件发生时的归属合并内政，失去本方城市仍突出，失败原因保留；完整事件引用不替换、不删改。纯外国内政批次与经济结算默认投影为两条本方银粮净变化，其他势力变化折叠。
- **层级**：新增一项检查固定高层弹窗的挂载不再抬升可拖拽指挥面板，避免指挥盖住目标链和大事记。
- **回归总计**：37 个测试文件、424 项测试通过，包括先前真实回复的离线回放。离线回放不是新的一局真实模型对战。

类型检查、前端和后端构建通过；ESLint 现有配置只检查 JS，不包含 TS/Vue。Oxlint 仍有 41 项既有错误，没有把这项检查描述为全绿；最终主包约 790.75 kB、gzip 233.22 kB，拆包警告仍在。

## 下一步判断

目标链现在提供可见的“夺取、整合、守住”闭环，快速演出和聚合摘要减少例行信息干扰，但固定空行动敌方下的任务完成不能证明更耐玩。下一优先级是敌方主动目标与反击，并用十至十五回合真实模型对局检查宜宾/昭通争夺、补给中断、真实失败后的计划调整；不急于扩科技树或复杂运输系统。
