# 势力主动目标验证范围

本轮没有新增界面控件。重点验证敌方行动与前线反馈，同时把真实模型规则引擎测试、浏览器离线响应重放及自动回归明确分开。

## 验证清单

- **目标生成**：受攻防守、支援已开战来源、恢复断供、整合占领、近期失地、准备充分收复、超过六回合失地、重新夺回、和平及同盟停战。单元测试检查目标与正常执行边界；公开建议不修改世界状态。
- **可信失败反馈**：结构和战略预检拒绝记入零费用回执；保存加载后仍可见；后续提示使用当前余额。旧的历史与上下文回归必须通过。
- **真实压力局**：分别十二回合的防守与合法失地场景，实际模型规划，实际规则、费用、战斗和日期推进；固定川系控制策略，其他势力等待，无外交结算，演出与战斗修辞替身。
- **浏览器流程**：原生输入川系开局进攻，结束回合，展示滇系真实首回合响应的离线重放，查看前线与聚合摘要。核实“实际执行”与“计划”不混同。
- **视觉检查**：桌面 1440×1000 和窄屏 375×812 的行动后摘要，查看层级、溢出、文字裁切和继续按钮。使用 Canvas 降级渲染，不作为设备 GPU 性能基准。
- **异常探索**：未执行失地预检、预算不足、零点数、历史城主易主以及停战不诱导战争由自动测试覆盖；浏览器检查关闭摘要后继续及窄屏滚动。
- **发布前回归**：完整自动测试、类型、前端与服务端构建；记录既有 lint 与浏览器助手限制，不把未通过项目写成通过。

## 结果

十四项专项及完整 438 项离线回归通过。原生浏览器输入、离线录制响应重放、桌面与窄屏摘要及继续按钮通过，截图检查后已关闭测试浏览器；正常存档续测的恢复状态一致性检查通过。

完整十二回合真实模型压力局未完成，后续调用失败即暂停，没有把联网测试默认跳过或短分段成功当作完整长测通过。通用游戏助手三十秒退出 124；全项目 41 条既有 Oxlint 错误与包体积警告仍存在。详细样本、失败和观察边界见 `faction-initiative-results.md`。
