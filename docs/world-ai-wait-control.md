# 世界回合 AI 等待控制：实施与验收

本轮承接地图两步选城修正后的“继续吧”，处理长时间世界回合等待、请求重试进度和停止等待。地图进攻／调兵的先动作、再选两城、最后弹出预览流程保持不变。

修复已通过 [PR #13](https://github.com/ZhengHaoF/map-war/pull/13) 合并到 `master`，合并提交为 `db356eb42e751afe6aaa873f6e9a3e40fe52ce31`。修复分支已删除，合并后本地和远端均只保留 `master`；同一私有预览已更新，云浏览器启动画面检查完成，浏览器已关闭。

## 用户可见变化

- **共享截止**：从 P3 世界决策开始计时，默认 180 秒；相关势力决策、无关势力批量决策、战斗调味和世界叙事共用同一截止，不在进入下一阶段时重新计时。
- **单次请求限制**：每次 HTTP 请求及响应体读取合计最多 90 秒。5xx、网络错误和单次超时可在共享截止内重试，4xx 不重试；退避等待也可以停止。
- **真实进度**：相关势力分别显示请求状态、尝试次数、重试退避和结果。无关势力明确标为“共享一份批量请求”，不伪造各势力独立请求进度；有效空计划与请求失败分开显示。
- **停止等待并结算**：停止未完成的模型等待，保留已取得的有效决策，继续一次正常本地结算。经济和已执行动作不回滚、不自动重跑；缺失战斗调味使用本地公式，缺失叙事使用默认七天日期规则。
- **入口与反馈**：指挥面板内显示倒计时、任务列表和停止按钮，关闭指挥面板后地图仍保留同一控制入口。超时、主动停止和格式失败通过原有 `aiStatus`、摘要和日志说明，不解释成敌方主动按兵不动。
- **存读档保护**：世界回合、调度动作或已接受的 AI 效果尚未结束时，UI 手动存档和读档拒绝，避免保存半个回合后重新经济结算。正常完成后的存读档功能保留，自动存档规则不变。

## 一致性边界

取消是“停止等待”，不是回滚整个回合。已经返回的计划仍执行，已接受的动作、战斗基础公式与日期演出必须正常结束；本地执行期间停止按钮不可用。

截止时间包括 P3 开始后的实际经过时间，但不强制终止本地动画或已接受的动作，因此不承诺整个回合必定在 180 秒以内完成。如果截止发生在本地执行期间，后续模型阶段直接降级，不再开启新请求。

底层等待包装同时处理遵守和忽略 `AbortSignal` 的实现。取消、超时或世界替换后的迟到结果不能添加订单、电报、外交提案、拒绝回执、叙事、日期或战斗调味；结束回合与直接世界回合入口共用防重入锁。

代码复核额外发现战斗调味结束后，本地战斗效果仍可能落在“等待中”的范围内。本轮增加调度器等待阶段回调，只在真正的调味请求期间启用停止按钮，并单独回归验证本地战斗效果不能中断。

## 自动验证

新增测试覆盖共享截止、单次 fetch／JSON body 卡住、取消退避、忽略 abort 的迟到成功和拒绝、已完成计划保留、唯一经济与日期事件、强制世界替换、下一轮隔离、存读档保护和真实调度器基础战斗公式。

新增 35 项测试分布在 `llmWait.spec.ts`、`worldAiWait.spec.ts`、`worldProgressBanner.spec.ts`、`schedulerAiWait.spec.ts`。真实调度器测试只替换模型 HTTP 返回，独立计算基础伤亡并检查基础战斗应用一次，迟到 shock 不追加效果。

全量离线回归 590 项通过，52 个测试文件通过；4 项需真实模型的测试跳过，不计入通过项。前后端构建与前端类型检查已通过，修改的 17 个 TS／Vue 文件 Oxlint 无错误或警告，4 项报告脚本测试通过；既有 bundle 大小提示和 jsdom canvas 提示不视为真实浏览器验证。

## 浏览器操作与状态对照

浏览器使用原生鼠标、键盘和真实游戏调度器，只有 `/api/ai/chat` 做故障注入与受控回复；只读检查不修改世界或生成伪造回执，未暂停 Pixi ticker。桌面为 1440×1000，窄屏为 375×812；软件渲染现场约 0–1 FPS，不把这一轮当作性能验收。

- **自然截止**：第一轮 HTTP 502 后进入重试，后续请求持续等待，默认共享截止最终触发。日期从 1931-04-01 到 1931-04-08，经济和日期各一个事件，批量决策与叙事都记录 `timeout`，没有新的叙事 HTTP 请求。
- **主动停止**：下一轮通过界面按钮停止批量等待，日期到 1931-04-15，累计经济与日期各两个事件。批量与叙事记录 `cancelled`，没有把未返回计划标为有效空计划。
- **已完成计划与叙事等待**：重新进入川军游戏，受控批量计划经真实规则执行北京征兵 1k。北京驻军 69→70、行动点 6→5、银扣 2、粮扣 1，成功回执只有一条；停止后保留征兵结果，日期推进至 1931-04-08，经济与日期仍各一个事件，行动点按正常新回合恢复。
- **存读档保护**：同一叙事等待期间，用实际 UI 新建存档被“暂不能保存”拒绝，存档数量仍为 2；实际 UI 读取已有存档被“暂不能读档”拒绝，世界回合仍保持 loading。
- **面板切换**：关闭、重开指挥面板的请求数量保持 8→8，地图入口继续显示完成的批量任务与未完成叙事。
- **窄屏适配**：地图等待面板范围 x=12、y=499、宽 351、高 249，底部 748；停止按钮 y=668..700，文档宽度 375，无横向溢出。等待状态和停止后的降级摘要均进行了视觉检查。

脱敏状态、事件计数、回执和请求清单保存在 [浏览器状态对照](fixtures/world-ai-wait-browser.json)。这里只包含游戏测试数据、受控请求分类与安全状态，不包含凭据、原始模型提示词或隐藏推理。

验收脚本曾因入场过渡尚未结束和 Vite 带时间戳模块导入重复实例而产生失效检查，已改为等待实际可见状态并读取应用加载的模块版本。热更新后的旧轮次不作为最终验收，最终原生操作重新进入游戏完成；没有据此声称发现新的生产玩法缺陷。

## 未覆盖与限制

- **真实模型连续对局**：本轮没有新增真实外部模型调用。故障注入证明前端和本地规则的等待边界，不证明模型服务稳定、模型策略合理或连续对局通过。
- **上游终止与费用**：浏览器 abort 不保证服务端或模型提供商立即停止生成，也不保证停止计费。本轮不新增生产后端取消协议，未验证生产 Nest 断连传播。
- **迟到回复**：忽略 abort 后继续返回的情况由离线测试覆盖；不声称已将回复成功送入取消后的浏览器传输再接受验证。
- **边界覆盖层级**：逐相关势力、强制世界替换、快速重复结束／停止、执行期禁止取消及迟到外交主要由自动测试覆盖。浏览器未新增开战来覆盖独立势力决策或战斗调味，不把测试夹具当作原生战斗对局。
- **标准游戏烟测**：执行一次后得到合法 idle／null-faction 状态，没有错误文件，但标准客户端的 canvas 截图为黑帧，不能据此认定启动视觉通过。普通原生浏览器全视口截图已显示实际地图与操作入口；标准脚本的黑帧问题单独记录，不当作完整对局或真实模型验证。启动存档恢复与页面热更新不在本轮新增修复范围。
