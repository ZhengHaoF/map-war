# 第一轮游戏性修改：规则边界与行动成本

本轮把自然语言沙盘的关键操作收敛为可验证的游戏规则，保留原地图、美术风格和存档版本。没有同步重做地域拓扑、初始经济或战斗基础公式；这几项应在规则稳定后通过长局测试单独调参。

## 已实施规则

- 玩家和各 AI 势力分别每回合拥有 6 点「回合行动点」。这是游戏内规则，与模型 API 额度、余额及 token 有效期无关。征兵、发展、筑防、整军、出征、出兵与调兵每条消耗 1 点；撤回己方战斗不消耗行动点。
- 占领、日期推进、切换玩家势力和判定势力存亡由可信系统路径管理。模型 JSON 中的 `authority` 或 `actor` 字段不能授予额外权限。
- 停战期攻击在调出兵力、支付行军成本和预留行动点之前拒绝。同一来源城只能维持一条正在进行的战线。
- 负面宣传与破坏每次消耗 1 点和 10 万银，同一目标城市每回合只能一次，换名称、换字段不能绕过；不能破坏同盟或停战对象。
- 自由筹饷、筹粮只能增加己方资源，每种资源每回合一次，每次至多 50。不能通过自由行动扣除第三方府库、单方面结盟或停战。
- 单次自由行动最多落实 3 项效果。界面显示实际执行的效果数和失败原因，而非照抄模型承诺。
- 回合行动点及重复限制写入事件日志，存读档重放后保持；日期推进后恢复行动点。旧存档仍可读取，但不能还原旧日志里未记录的历史行动消耗。
- 回合推进只接受合法、前进 5 至 10 天的模型日期；无效、倒退、过远或缺失日期回退为当前日期加 7 天。世界模型网络失败也不会卡死日历。
- 战斗叙事的同一方多个附加效果按总量约束，防止拆分效果绕过单项上限。
- 大额行军支出按事件上限分段扣款，避免大额费用被单事件截断而少付。
- 指挥面板显示剩余行动点，窄屏弹窗限制在视口内；移除了没有执行逻辑的右键操作项。

6 点、10 万银、50 的筹集上限与 3 项效果均是第一轮可调参数，不代表已经验证了最佳平衡。常量集中在 `apps/web/src/data/gameConfig.ts`。

## 验证记录

- 原有 290 项测试；新增 27 项确定性规则与日期测试。
- 使用 `step-5-preview` 实际调用 6 个场景，并将返回内容回放至生产解析、校验及执行链路；合计 24 个测试文件、323 项测试通过。
- 实际模型场景包括正常征兵、直接占领、停战期进攻、单方面结盟、超额反复筹饷、行动点耗尽后征兵。
- 模型在最后一个场景仍把征兵判断为可行，但执行层正确拒绝，没有修改驻军。这说明提示词不能替代硬规则。
- 前后端生产构建、前端类型检查与 ESLint 通过，`git diff --check` 通过。
- Oxlint 与未修改基线均有 41 条相同诊断，无新增诊断；不能称为整个 lint 流程已通过。
- 构建仍有主包超过 500 KB 的提示，本轮未处理包体拆分。
- 浏览器桌面 1440×1000 与窄屏 375×812 的指挥面板截图已检查，行动点完整显示。使用真实返回内容进行 UI 回放，正常征兵从 6 点降为 5 点，银粮从 1200/720 降为 1198/719；测试中刻意耗尽游戏内行动点后的征兵拒绝没有再次扣款，界面显示拒绝原因，不代表用户 API 额度耗尽。
- 浏览器测试未观察到页面脚本异常；Pixi/Chromium 的部分指针动作超时，部分操作用 DOM 点击事件继续验证。标准游戏测试脚本初次截图过早为黑色，增加帧等待后的最终截图正确显示地图与开局界面；指挥面板、正常征兵及额度拒绝另由完整页面截图确认。不能把开局冒烟运行当作完整多回合交互通过。

真实模型回放的动画是测试替身，验证的是规则执行结果，不等同于完整多回合实机对局。未运行几十回合的全势力模型联机模拟，也未验证新参数下的胜率、经济雪球和中盘难度。

## 复现方法

使用符合项目要求的 Node.js 版本及 pnpm：

```sh
pnpm install --ignore-scripts
pnpm --filter warlords-1931-web exec vitest run --pool=threads
pnpm --filter warlords-1931-web run typecheck
pnpm --filter warlords-1931-web exec eslint .
pnpm -r run build
```

真实模型测试是可选的，默认测试不要求密钥。认证由安全 HTTPS 凭据代理注入，脚本不接受或保存 API key：

```sh
node scripts/smoke_gameplay_model.mjs /absolute/path/model-responses.json \
  https://api.stepfun.com/step_plan/v1 step-5-preview
MAPWAR_LLM_REPLAY=/absolute/path/model-responses.json \
  pnpm --filter warlords-1931-web exec vitest run --pool=threads
```

返回内容可能包含模型推理和对话，不应直接提交到公开仓库。用户的测试密钥与原始模型响应均未加入本次提交；后端默认配置也没有永久切换到该临时密钥或模型。
