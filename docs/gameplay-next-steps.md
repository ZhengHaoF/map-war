# map-war 下一轮游戏性优先级

当前优先目标是让玩家在地图上产生明确的“先打哪里、为什么、付出什么”的选择，不是继续增加自然语言指令数量。本建议是开发顺序，不是工期承诺；连接规则、前线预览、轻量补给与占领整合已完成首版实现，详见 `docs/campaign-connectivity.md`。40 回合脚本经济与策略基准已建立，详见 `docs/economy-benchmark-report.md`；这不是完整真实模型对战，不能仅凭脚本结果宣布平衡完成。

## 已实现首版：可达规则与可进攻目标

- **原问题**：此前距离存在不等于存在合法路线。现在 375 城市连接图、只经己方中转的路径和前线预览已接入，相关实现见[项目代码](https://github.com/ZhengHaoF/map-war)中的 `campaignRoutes.ts`、`campaignPreview.ts` 与 `gameplayRules.ts`。
- **范围**：先整理城市连接图，玩家和 AI 共用 `canAttack` / `getAttackableTargets`；选择出发城时显示合法目标、行军费用和不合法原因，执行层再次检查。
- **边界**：先验证一个区域的连接数据与手工样例，再铺开全国；岛屿、海峡、飞地与跨友军通行必须单独定义，不能把直线最近城市直接当作真实邻接。保留已有存档和地名解析。
- **验收**：同城、无连接、穿越敌占区域、停战等非法进攻在任何扣款前拒绝；合法边境进攻正常执行；AI 候选目标与玩家界面一致；读档和地图缩放不改变连接关系。
- **收益假设**：疆域连续性、侧翼与要地将变得可理解。需要实机对局验证，不能仅凭单元测试宣布游戏性提升。

## 已实现首版：轻量补给与占领整合

- **依赖**：连接图先稳定，才能可靠判断连通与断供。
- **当前实现**：已整合等级 3 城市及开局区域中心提供补给；断供使攻方有效战力降低 20%，新占城整合 2 回合期间税粮为 50%。界面、AI、日志与存档兼容路径已接入，需长局验证系数。
- **范围**：优先引入一条简单补给规则，例如前线是否与己方补给城连通；占领后有短期整合成本。先显示状态和原因，再应用可调的成本或战力影响。
- **避免**：第一版不要同时增加铁路、运输车辆、天气和复杂库存网络，以免掩盖基础选择。
- **验收**：断供产生确定性、可解释的后果，重新连通后恢复；补给变化进事件日志，存读档结果一致；玩家能在发动攻击前看到风险。

## 当前进展：经济压力与阶段目标

- **经济**：先做 20 至 40 回合可复现模拟，记录每势力银粮净收支、兵力、领土、战斗和行动点利用率，再调整维护费与扩张成本，不凭直觉统一削弱所有势力。
- **AI**：从合法候选目标中选择“整备、集结、防守、扩张”等阶段目标，按真实预算排出有限行动，并记录放弃某条指令的原因。
- **中盘**：在地图目标能成立后，再设计区域控制、关键节点或阶段任务，让胜负推进不只靠一直征兵和逐城占领。
- **指标**：统计无效指令率、开战回合数、连续空行动回合、经济破产与失地原因，并结合实际试玩判断是否存在有效取舍；不预设未经验证的胜率目标。
- **本轮落地**：40 回合、12 势力、三种常规脚本策略与额外缺粮压力场景；修正前后共 9600 条势力回合记录。未改税收与维护费系数，修复小驻军和外出部队缺粮免疫，增加静态收支、储备回合、征兵建议与阶段提示；旧经济事件按原算法重放。

## 下一阶段：真实模型计划评估与中盘目标

- **先测模型**：评估新上下文下整批指令的总成本、长期维护负担、合法目标选择与失败后的调整；记录真实模型无效指令率，不用脚本预检后的零拒绝代替它。
- **再加目标**：在真实模型能正确选择整备、集结、防守和扩张后，小范围加入区域控制或关键补给节点任务，明确可见的进度与完成条件，不同时扩充复杂交通网络。
- **保持可复现**：脚本基准、参数和报告生成器留在仓库，真实模型返回单独留存并脱敏。当前长局脚本不包含外交或世界事件，因此不能作为全面胜率或历史准确性的结论。

### 本轮推进：实机反馈与回合可靠性

已通过川军真实 UI 和 `step-5-preview` 完成征兵、进攻昭通及整合操作；实机发现并修复云雾掉帧造成的“提示推进但实际未推进”。新增可存档的只读执行回执，让后续玩家和势力上下文保留成功/失败、原因、实耗与剩余预算。真实回复脱敏保存在 `tests/fixtures/live-play-step-5.json` 并单独重放；这不是又一局实玩，详细边界见 `docs/live-play-review.md`。

本轮实现了“西南短战役目标链 + 世界常规内政快速模式”：川军可选择夺取昭通、完成整合并保有宜宾与补给，再连续守住三个完整回合。任务进度可存读档，完成后继续全国沙盘；没有奖励资源或新全国胜负条件。可信势力调用的常规内政可省略动画和成功提示，费用、行动点、战斗和调兵规则不变，玩家演出不被跳过。

大事记现以本方银粮净变化、本方军事和外交、未执行原因为主；其他势力例行变化与完整事件默认折叠。摘要保留失地信息，按事件发生时的归属归集内政，原始日志不删除。详见 `docs/southwest-campaign.md`；录制 25 条内政的普通/快速对照是规则回归，不是新的真实模型对局或服务响应时间测试。

## 下一优先级：真实敌方压力与受挫调整

- **长局验证**：用真实模型走十至十五回合，记录响应失败与有效回复，观察滇系是否会反击昭通、争夺宜宾或打断补给；不能把固定空行动响应当作敌方战略水平。
- **受挫后的调整**：保留预算不足、非法路线、失地与断供的真实失败样本，检查下一次决策是否减少兵力、换路或转向防守，而不是重复同一失败指令。
- **目标是否有效**：观察玩家能否不问模型就知道当前阶段、为何没有增加守住计数，以及何时该停攻整备；目标链首版提供可见闭环，不等于已证明长局耐玩。
- **之后再扩展**：若明确任务和敌方压力能形成有效选择，再考虑其他势力战役或关键节点任务；暂不叠加科技树、铁路和复杂运输。

完整真实模型长局、敌方持续反击与失败后调整的统计评估仍未完成，不能以几个成功批次或离线零拒绝代替。请求失败现在显示可读错误并保留输入；这让错误可恢复，但不等于上游服务故障已被游戏修复。

## 工程加固

常规动画异常后的资源与兵力需要统一事务回滚；既有静态检查问题和主包拆分应单列处理。它们不会直接创造新的战略选择，但应与地图规则开发一起防止状态损坏和反馈失真。
