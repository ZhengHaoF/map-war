# 地图进攻／调兵快捷入口评估

结论：建议做。它能把“在两个下拉列表里寻找城市”改成“在当前战场直接点出发城和目标城”，更适合地图策略游戏；这是交互设计判断，尚未进行新交互的用户测试。本轮只评估，没有增加按钮、快捷键或地图选城逻辑；当前实现范围见 [PR #8](https://github.com/ZhengHaoF/map-war/pull/8)。

## 推荐流程

- **入口**：工具栏保留“进攻”“调兵”两个可见按钮。已经选中己方城时，直接使用它作为出发城；没有选中时，进入“请选择己方出发城”。移动端同样可用，不依赖键盘。
- **地图点选**：选择出发城后，显示“从宜宾进攻，请选择目标城”或“从昆明调兵，请选择目的城”。进攻强调可达敌城，调兵强调通过己方连接可达的己方城，标出出发城与目标城。
- **回填面板**：选中目标后打开既有“前线·行军预览”面板，自动带入出发城、目标城、行动类型。兵量可编辑，显示实际路径、行军银粮、行动点、留守、双方士气与基础风险。
- **最终确认**：仍需点击面板里的确认按钮才执行。地图选城、修改兵量和查看预览都不能扣费、出兵、宣战或推进日期。
- **取消与重选**：Esc、取消按钮退出选城模式；提供“重选出发城／目标城”。点空白不执行，拖动地图不算选择，切换势力或读档清除选城草稿。

如果出发城已经选中，流程可缩为“进攻按钮 → 点敌城 → 调整兵量并确认”。“先点己方城，再点动作”与“先点动作，再选两城”应进入同一套草稿流程，不另做两套规则。

## 为什么比现在更方便

- **空间对应**：玩家看到地图上的相邻关系、方向和前线时就能选择城市，不必把地图名称再与按名称排序的下拉列表逐个匹配。
- **减少输入负担**：城市编码、中文名称、行动类型由界面带入，普通调兵不必输入自然语言。复杂计划仍可使用现有 AI 指挥入口。
- **保留战术取舍**：快捷的是选城，不是省略决策。兵量、费用、后方留守、路线合法性和双方士气仍留在确认面板中。
- **保留替代入口**：下拉列表不删除，密集城市、小屏幕或地图难以点中时仍可用列表；城市右键菜单也可提供同样两个动作入口。

上述收益是基于截图和现有代码的设计推断，不是已经测得的点击次数、操作时间或转化提升。

## 与现有代码的衔接

本次检查的版本中，`LeafletMap.vue` 已有城市命中、选中高亮、右键菜单和 `openCampaign(gb)`，但目前只把出发城交给面板；`CampaignPanel.vue` 目前只接受 `initialSourceGb`，目标城和行动类型由面板内部管理。规则层已经有 `previewCampaign`、路线计算及调度器的执行前复检，可以复用，不必增加一套地图专属指令或让模型负责普通选城（[当前改动与实现](https://github.com/ZhengHaoF/map-war/pull/8)）。

- **选城状态**：建议用明确状态 `idle → pickingSource → pickingTarget → reviewing`，草稿保存行动类型、出发城和目标城。显示清晰的当前步骤，不能用两个零散布尔值隐式表示。
- **数据交接**：面板接收一个明确的草稿对象或加载草稿动作。注意当前监听出发城／行动类型变化的 watcher 会清空目标城和重置兵量，不能直接依次赋值三个字段，否则可能把刚带入的目标擦掉。
- **地图输入分流**：选城模式中有效城市点击交给草稿处理，普通模式维持原有信息展示。鼠标拖动、右键菜单、弹窗关闭、Esc 取消相机演出必须有明确优先级。
- **预览与执行**：高亮候选依据现有路线、归属和外交约束；预算随兵量变化，在面板中检查。不要仅凭地图高亮就执行，确认时仍按最新世界状态复检。
- **不可用提示**：敌城不能作为出发城、调兵不能选敌城、同城不能作目的城；无路线、穿越第三方、停战／同盟、忙碌状态都要解释原因。高风险但合法的进攻仍可确认，不能当作非法目标禁用。

## 快捷键与小屏幕

建议第一版优先完成按钮与地图点选，之后再考虑 `A` 进入进攻、`M` 进入调兵、Esc 取消。字母只是候选映射，不是这轮已经绑定的快捷键；实际落地需检查地图及未来控制的冲突。

输入框、下拉列表、文本编辑区或输入法组合输入期间，不触发字母快捷键。模型决策、行动演出和执行中不进入新的选城模式；手机需要始终可见的步骤提示与取消按钮，目标选定后再弹出面板，避免大面板先挡住地图。

## 首版边界与验收

- **只做一个指令草稿**：先不加多城市编队、框选、多段路线、连续排队、长按菜单或自动发兵；不改变行军、战斗、外交、补给和费用规则。
- **回填正确**：两种入口顺序、两种行动类型均能准确带入两座城市，切换模式不残留敌我不匹配的旧目标。
- **取消无副作用**：Esc、点取消、关面板、读档和切换势力都不扣兵、银粮或行动点，不留幽灵高亮。
- **执行无绕过**：预览到确认期间归属／余额／行动点变化，调度器仍正常拒绝；确认后只执行一次，防重复点击。
- **地图操作可靠**：拖动不误选、点空白不发兵、城市密集时可退回下拉选择，桌面与窄屏都能看到取消与确认按钮。

建议在现有可靠性修复合并之后，单独做一个小 PR 实现。当前没有开始这项修改，也没有把这份评估当成实现授权。
