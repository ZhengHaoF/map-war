# 战术成本、风险与受挫调整首版

PR #7 已按用户授权合并到 master（合并提交 `89da24b`）。本轮在其基础上增加战术比较，不改变战斗公式、费用、补给系数或六点行动预算，也不自动执行建议。

## 范围与验收清单

- **共享基础比较**：玩家前线面板和势力 AI 使用同一模块，调用既有 `computeBaseBattle`，采用实际行军计费距离、远征衰减与当前补给；报告下一次结算的基础攻守减员及士气，而不是长期胜率。
- **解释风险**：根据比例消耗、士气崩溃区间、留守兵力与断供给出“风险较高 / 需要权衡 / 相对有利”。未计入下一次经济减员、后续增援、AI 突发事件和真实崩溃结果，不承诺胜负。
- **合法不等于有利**：风险提示不禁止合法玩家进攻，不为非法、无路线或停战行动生成可执行预测。AI 原有兵力建议加入基础比较，但模型仍可选择其他合法动作。
- **预算不足**：只对银粮不足的行军例子做十分之一 k 粒度的缩量搜索，每次复用正常检查；不靠缩量修复停战、同盟、无路线或无行动点，不自动扣费。
- **已有战线**：现有行军费为已付费用，不重复计收；比较支援、整军与合法撤退。零行动点仍可展示本方合法撤退，不替守方撤销敌方战线。
- **失败原因**：分别提示字段修正、按当前资源重算整批、等待行动点、遵守外交或重新选择合法路线。分类提示不是自动改写或执行模型指令。
- **兼容与纯读取**：旧存档战线保留旧补给版本的结算语义，存读档前后评估一致，预览不修改世界状态。

## 浏览器验证结果

在现有 Canvas 降级渲染下使用原生输入，开局选择川系，打开前线，选择宜宾与昭通。桌面 1440×1000 和窄屏 375×812 的截图均已检查，无页面错误或横向溢出；增加内容后发现桌面面板底部被裁，已局部调整初始位置、最大高度与内部滚动，不改变全局拖拽规则。

- **1k 高风险进攻**：下一次基础攻损 1k、守损 1k，来源留守 7k，预估攻方士气 12、守方 27；确认按钮仍可用。原生点击确认实际扣除银 2.4、粮 1.8、行动点 1，正常建立战线，日期未推进。
- **8k 留守风险**：来源留守变为 0k，显示需要权衡，合法确认仍可用。9k 超驻军和 0k 非正兵力被正常拒绝，非法预览不显示可执行战术估计。
- **调兵与纯读取**：调兵模式不显示攻城预测；反复修改预览后世界日期、行动点、银粮及战线与修改前相同，只有确认执行后才扣费。
- **测试边界**：本次浏览器验证没有模型调用或响应替换，也没有走完整战役。软件 Canvas 帧率不是设备性能基准；开发 HUD 不进入生产包。
- **通用游戏助手**：本轮有界运行退出码 0，开局截图与状态已检查。但仅完成开局静止截取，不作为完整玩法流程通过的证据，也不据此宣称此前所有助手问题已修复。

## 自动验证与真实模型样本

新增 24 项战术专项回归，覆盖既有战斗公式、实际下一次结算、城防地形、行军与补给、预算缩量、留守、旧存档版本、合法零点撤退及分类失败提示。全量 39 文件、462 项离线测试通过，2 项联网测试默认跳过；其中既有真实输出离线重放不增加联网样本。类型检查、前后端构建与 JavaScript ESLint 通过，四个相关代码和测试文件 Oxlint 无错误。既有全项目 lint 问题与主包体积警告仍单列，不声称全项目 lint 已通过。

本轮另外新调用一次 `step-5-preview`，HTTP 200，耗时 44,573ms，无重试。正常规则引擎下的收复昭通场景完成一个有效势力决策回合；固定川系控制策略、其他势力等待，无外交结算，演出与战斗修辞替身，因此不是原生浏览器真实模型长局。计划十二回合的覆盖记录仍为 `complete: false`，不能写成十二回合通过。

当前提示建议先集结：示例 13.5k 出兵、来源留守 4.5k，基础攻损 2k、守损 1k，费用银 74.4、粮 55.8，标记需要权衡。模型没有采纳先集结建议，而是选择昆明出兵 10k 反攻昭通、昆明筑防 5、征兵 3；三条均按正常规则成功执行，实际合计 3 行动点、银 66.1、粮 44.4，无预检或执行拒绝。回合末昭通仍属川系，不能由此判断反攻长期收益。

这证明建议不是强制执行限制，以及本次模型选择可通过正常规则执行；不证明模型变得更谨慎、已经学会受挫调整或长期平衡成熟。PR7 的四段短样本与本轮这一回合分开计数，不用旧响应证明新提示效果。

## 游戏性判断与下一步

这轮首先改善“为什么值得打、会付出什么”的可读性，让同一合法目标的出兵量、留守与预期消耗形成可见取舍。它尚未证明耐玩度或长期对手策略提升，基础比较也不是完整战斗预测。

下一验证重点是同一场景完成 10 至 15 个有效回合，分段正常存档续测，逐条比较推荐与实际选择，观察持续支援、主动撤退及预算/路线受挫后的调整。请求失败就暂停，不记作空行动有效回合；先积累真实选择和结果，再决定是否调整提示强度、风险阈值或策略目标，暂不叠加新战役与复杂系统。
