# 正反馈设计评估报告

> 项目：烽火舆图 / Warlords 1931
> 评估日期：2026-08-10
> 评估范围：基于代码（`apps/web/src/`）与文档（`docs/`）的正反馈（positive feedback）循环与奖励反馈机制

## 一、一句话结论

游戏**结构性正反馈（滚雪球）真实且偏强**，但**让玩家"爽到"的奖励反馈偏薄**——宏经济层在滚雪球，表现层（动画/电报/回合总结）很会"演"，但**系统性的"赢的奖励"和"长期成长感"是缺口**。属于"雪球够大、但每口雪不甜"的状态。

## 二、现状评估

### 强项

| 维度 | 评价 | 证据 |
|---|---|---|
| 经济雪球 | ✅ 强 | `economy.ts` 税基 = Σ(城等×2 + 工业×0.3)，占城即扩税基→养更多兵。KMT 开局 191/380 城，先发优势固化 |
| 占领正反馈 | ✅ 强 | `CAPTURE_MORALE_BONUS=12` + 直接接管守军 `troops`，占城兵力不降反增 |
| 表现层奖励（juice） | ✅ 优秀 | `WorldProgressBanner` 印章、`TurnSummaryModal` 大事记、`capture`/`battle`/`cloud` 动画、电报、顾问——"爽感"主要靠这层 |

### 弱项

| 维度 | 评价 | 证据 |
|---|---|---|
| 单胜奖励 | ❌ 薄 | `docs/战斗系统设计文档.md` §6.5（L342–370）明确为"已定方向、参数待确认、未实现"。攻方胜无士气提振、无战利品、无威慑扩散；败方全灭无残部 |
| 被动恢复/成长 | ❌ 无 | 无每回合兵力/士气自然恢复，增长只能"花钱扩军"或"抢城"，雪球靠"抢"不靠"养" |
| 元进度（科技/分数/成就） | ❌ 缺失 | 设计文档 §11 的科技树/人口均为"未来扩展"，代码无 `tech`/`score` 实现 |
| 负反馈张力 | ❌ 缺失 | `aiClassify.ts` 无 `leader/霸主/围/coalition/联合` 逻辑，滚雪球无天花板，玩家也**不会被群雄围攻**（落后时同样无追平机制）|

## 三、可加强的方向（按 ROI 排序）

### ① 落地 §6.5 单胜奖励（最高 ROI，设计已写好）
- **位置**：`useGameScheduler.ts` 的 `settleActiveBattles` / `battleFormula.ts`
- **内容**：攻方胜 `morale +10`、守方胜 `+5`、败方周边友城 `−5` 威慑扩散；`attackerRouted`/`attackerCollapse` 保留约 40% 残部逃回来源城。
- **价值**：让"赢"在士气上留下痕迹，而非只换地盘。改动量约 30 行，replay 安全。

### ② 给"领先"配一个负反馈张力（反而增强正反馈体验）
- **位置**：`aiClassify.ts` 的 `classifyFactions`
- **内容**：某势力城数/兵力超阈值时，其余势力 `related` 概率上升、倾向结盟围堵。
- **价值**：玩家变强后收到**称臣电报、进贡、联盟求饶**——"被恐惧"本身就是顶级奖励；同时避免雪球后期无聊。落后时也能提供追平/挣扎的戏剧性。

### ③ 把奖励和"城市属性"挂钩，避免每场胜利一个味
- 占工业城 → 触发"工业红利"事件 + 专属电报；占首都 → 大士气 + 专属动画。让不同胜利有**差异化高光**，而非千篇一律的 +12。

### ④ 加一个可见的"统一进度 / 势力评分"仪表
- **位置**：`PlayerStatusPanel.vue`
- **内容**：势力评分条或"天下一统 X%"进度。雪球需要一根**看得见的刻度**才会有"我在变强"的体感。

### ⑤ （长线）科技树 / 势力特质解锁
- 让成长有"解锁新能力"的层次感，而不只是"攒地攒兵"。这是元进度缺位的根本补法。

## 四、关键提醒

**现在不缺正反馈、缺的是反馈的"质感"和"天花板对手"。**

纯加正反馈（如再多给占领奖励）会让雪球更失控、后期更无聊。真正的加强点是三者合力：

1. **让每次胜利更甜**（落地 §6.5）
2. **给强势玩家配对手制造戏剧峰值**（AI 围堵 + 称臣反馈）
3. **给成长一个可见刻度**（评分/进度仪表）

三合力，玩家"我在滚雪球"的爽感才会从"演出来"变成"系统里长出来"。
